# SocialAcolyte's Homebrew tap

```sh
brew tap socialacolyte/tap
brew trust socialacolyte/tap          # Homebrew 7 asks you to trust a tap before using it
brew install --cask monet-shot
```

**[Monet Shot](https://github.com/SocialAcolyte/monet-shot):** a menu bar screen recorder for macOS 26
on Apple Silicon that frames your demos like paintings.

Monet Shot is not notarised by Apple yet: the first time you open it, go to
System Settings › Privacy & Security and click **Open Anyway**.
